# 🧮 Projeto Calculadora

Calculadora desenvolvida como projeto de prática em desenvolvimento web, com uma interface simples para realizar operações matemáticas básicas.

## 💡 Sobre o projeto

O projeto consiste em uma calculadora desenvolvida utilizando **HTML, CSS e JavaScript**, colocando em prática conceitos de estruturação de páginas, estilização e interação com elementos da interface.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## ✨ Funcionalidades

* Adição
* Subtração
* Multiplicação
* Divisão
* Números decimais
* Botão para limpar a operação
* Botão para apagar caracteres
* Operações com números inteiros e decimais

## 🎯 Objetivo

Praticar conceitos fundamentais de JavaScript, como manipulação de elementos HTML, eventos e operações matemáticas, além de desenvolver uma interface de calculadora utilizando HTML e CSS.

## 📸 Projeto

Interface de calculadora com display numérico e botões para realização das operações.
